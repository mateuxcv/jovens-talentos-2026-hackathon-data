# Histórico de uso de IA

Esta pasta deve conter a exportação integral, em texto ou JSON, das sessões de
IA utilizadas no desenvolvimento. Resumos não substituem o histórico completo
exigido pelo desafio.

Antes da entrega, exportar esta conversa para esta pasta e conferir que prompts,
respostas, iterações, críticas metodológicas e correções estejam legíveis.
